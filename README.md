# Nebula Setups

A bilingual (English/Spanish) concept landing page for a cloud gaming desk setup. Built with HTML, CSS, and vanilla JavaScript as a portfolio demonstration.

[View the live demo](https://carlos2024r3223rw.github.io/nebula-setups-landing/)

## Experience

- EN/ES language switch, with the selected language saved in local browser storage.
- Responsive product showcase featuring the illustrated UltraView monitor, KeyForge keyboard, and Vortex Pro mouse.
- Interactive configuration demo: choose lighting and a play style to see a local summary.
- Animated statistics and scroll reveals, with reduced-motion support.
- Keyboard-accessible controls and a native dialog for the configuration flow.

The setup, specifications, price, and usage stories are **illustrative concept content**. The configurator does not take payments, place orders, create reservations, or transmit any information. Cloud gaming quality and compatibility depend on the user's connection, device, and service.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## Project files

- `index.html`: page content and configuration dialog.
- `styles.css`: responsive visual design and interface states.
- `script.js`: language switching, local configurator, and visual interactions.
- `assets/images/`: hero and product artwork.

To update the copy, edit the Spanish source text in `index.html` and its English counterpart in the `english` map in `script.js`. The English `alt` and accessibility labels are configured separately in the same script.
